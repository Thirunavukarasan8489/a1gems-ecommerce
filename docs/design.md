# Public Website Design Guidelines

## Color Palette
The public website uses a highly curated brand palette:
- **Plum (Brand Neutral)**: `plum-50` through `plum-950`
- **Gold (Primary)**: `gold-50` through `gold-900`
- **Emerald (Secondary/Success)**: `emerald-50` through `emerald-900`

## Core Principles
1. **Premium & Editorial**: Generous whitespace, large product photography, clean typography.
2. **Typography**: High-contrast sans or elegant serif for headings; clean sans-serif for body/UI text.
3. **Primary CTAs (Gold)**: Buy/Checkout buttons should use `gold-500` background with `gold-600` hover states and `plum-950` text.
4. **Secondary CTAs (Emerald or Plum Outline)**: Enquire/WhatsApp buttons.
5. **Interactive & Dynamic**: Implement micro-animations, smooth hover states, and transitions to ensure a living, premium feel.

## Structural Elements
- **Cards**: Minimal chrome, subtle `plum-200` borders with soft shadows.
- **Header/Navbar**: Premium dark `plum-900`/`plum-950` background or light `plum-50` with gold accents.
- **Badges**: Use `emerald` for in-stock/success, and `gold` for low-stock/warnings. Avoid pure red except for destructive errors.
